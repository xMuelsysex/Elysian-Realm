Create a high-fidelity product UI mockup screenshot for a web admin/observer dashboard called "Elysian Realm Observatory". It is a React/Vite local multi-agent simulation viewer, not a chatbot and not a generic SaaS analytics dashboard.

Design direction: dark celestial observatory control room, elegant sci-fi fantasy HUD, inspired by AI Town's playful game shell, ALICE_PROJECT's replay viewer HUD, and OpenStory's atmospheric character dossier panels. CSS-only web UI style, no 3D rendering, no real logos, no Pixi/Phaser canvas dependency implied.

Canvas: 2048x1152, desktop web screenshot, 16:9, crisp UI design, polished visual hierarchy.

Layout:
- Full-screen dark starfield / nebula background with subtle grain and vignette.
- Top fixed HUD bar: left title "Elysian Realm Observatory", subtitle "Backend snapshot projection", center world time "Day 01 · 09:35", right status pills "running", "3 agents", "86 events", language toggle.
- Beneath top HUD, segmented navigation with six compact tabs: Overview, Map, Agents, Events, Control, Debug. Active tab is Map.
- Main content is a three-zone observation layout:
  1. Large central map stage occupying most of the screen. It looks like an abstract realm map, not a technical graph. Use floating location islands / rooms connected by glowing cyan-gold paths. Locations: Atrium, Archive, Garden, Workshop, Observatory. Each location card has occupancy count and latest activity.
  2. On the map, show three stylized agent avatars/chips with halo rings, initials, small status labels, and speech/activity bubbles. Example bubbles: "Preparing a routine", "Reviewing a memory", "Moving to Garden". Bubbles must look like readable UI speech bubbles, not comic art.
  3. Right side sticky character dossier panel for selected agent "Elysia". Include monogram portrait, status badge, current action hero text, current location, relationships count, recent events count, memory indicators, and clear provenance badges: configured, runtime, generated, user.
- Bottom replay HUD bar: play/pause button, previous/next step buttons, speed pills 0.5x 1x 2x 4x 10x, wide progress bar, event cursor "42 / 86", selected event preview with event id and source badge. Make live auto-step visually separated from replay playback.
- A slim event timeline column or drawer near the lower right with 4 recent event rows, each with source badge and timestamp.

Visual style:
- Primary colors: deep navy #08111f, midnight #0f172a, translucent slate panels, cyan glow #7dd3fc, warm gold #f6c76b, jade green #4ade80, rose error #fb7185.
- Use glassmorphism carefully: translucent panels, 1px gold/cyan borders, soft backdrop blur, readable contrast.
- Use rounded cards, soft shadows, subtle glowing paths, status rings, small UI icons using simple geometric shapes only.
- Typography: modern sans-serif, large confident title, clear labels, all text readable. Avoid tiny illegible microtext.
- Accessibility: high contrast text, visible focus/selected states, no color-only meaning; badges include text labels.

Avoid:
- Do not show code editor, terminal, charts-heavy analytics, stock photo people, realistic humans, fantasy warriors, anime characters, logos, branded assets, browser chrome, mobile layout, 3D isometric scene, unreadable decorative text, cluttered debug JSON as primary content.
- Do not mutate or imply editing world state directly; the UI should feel like observation plus typed input controls.
