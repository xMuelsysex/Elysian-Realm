# Bilibili Elysian Realm Story and Analysis Index

## Purpose

This index maps public Bilibili metadata for Honkai Impact 3rd Elysian Realm / Flame-Chaser research into project-useful categories: story navigation, character event discovery, relationship hooks, and worldbuilding analysis.

This document is an index and summary only. Do not copy video transcripts, official dialogue, full plot text, images, audio, or extracted game assets into this repository.

## Use Policy

- Store BV IDs, URLs, creator names, titles, public part titles, durations, and project-authored summaries only.
- Use full-story videos as navigation to locate in-game story segments; do not treat uploader ordering as strict canon chronology unless corroborated.
- Use analysis videos as fan-analysis provenance, lower priority than official pages or wiki summaries.
- Future persona facts should cite these as `fan-navigation` or `fan-analysis`, not as official text.

## Mapping To Future Simulation Data

### Event Categories

Use Bilibili part titles to locate content, then summarize in project-authored words:

- `realm.main_story`: chapter act-level story beats.
- `realm.recollection`: historical memory fragments tied to one or more Flame-Chasers.
- `realm.character_event`: optional/side interactions; good for daily-life and relationship routines.
- `realm.object_memory`: object/item descriptions, archive entries, or memory artifacts.
- `realm.relationship_map`: relationship graph and directed relationship seed validation.
- `realm.system_event`: Klein/admin, anomalies, Deep End, Elysian Realm maintenance, or corruption/anomaly events.
- `analysis.previous_era_plan`: fan-analysis for Stigma/Ember/Ark/etc. terminology and trade-offs.

| Data need | Best Bilibili source category | How to use safely |
