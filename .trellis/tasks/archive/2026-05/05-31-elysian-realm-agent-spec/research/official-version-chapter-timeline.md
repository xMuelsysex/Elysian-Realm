# Official / Version / Chapter Timeline for Elysian Realm Research

## Purpose

Index the release-order context for Honkai Impact 3rd's **Elysian Realm / 往世乐土**, the **Thirteen Flame-Chasers / 逐火十三英桀**, and the follow-up **Elysium Everlasting / 永世乐土** main-story arc.

This document is a source index and project-authored summary. It must not copy official story text, dialogue, transcripts, cutscene text, images, audio, lyrics, subtitles, or extracted game assets.

## Provenance Policy

- `official-url`: HoYoverse/miHoYo URL is recorded, but browser extraction returned only JavaScript `Loading...`.
- `secondary-readable`: Fandom or wiki page was readable and used for high-level release ordering.
- `fan-navigation`: Bilibili BV or playlist can locate story material, but no transcript is stored.
- `project-authored`: concise interpretation for future simulation design.

Short names, version titles, chapter titles, battlesuit names, and URLs are retained only as identifiers.

## Source Reliability Notes

- HoYoverse official news pages are canonical URLs but currently JS-rendered in `web_fetch`; treat them as URL anchors unless manually verified in browser.
- Fandom version pages are readable secondary sources and provide useful release-order summaries, official-source links, and ER update bullets.
- Fandom chapter pages include mission text and quote-like snippets; do not copy them into this repository. Use only chapter names, mission-group labels, and project-authored summaries.
- Bilibili story collections remain navigation aids for manual checking, not transcript sources.

3. Chapters XXIX–XXXI should be represented as high-level background constraints and memory-fragment categories, not recreated as a playable plot.
4. Character release order should seed source provenance and UI filters; it should not become the sole source for persona behavior.
